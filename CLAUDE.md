# Game Day

Viewing planner: builds a day or week plan of games with channel and streaming service, tailored to the visitor's area. See README.md and `docs/` for the build brief and data pipeline.

## Skills to load

Load the matching skill before the work, not after. If a skill is not available in the session, say so instead of skipping it silently.

- **web-interface-guidelines**: any UI change, including the planner, multiview, team range view and all three themes (touch targets, keyboard, focus, motion, layout, accessibility).
- **react-nextjs-performance**: any change to the Next.js app in `app/`, `components/` or `lib/` (data fetching, server components, bundle size, re-renders).
- **web-page-quality-pass**: any copy, first-visit flow, landing or shared-plan page change, and before calling a page ready to ship.
- **code-review-standard**: before merging any branch to `main`, and when reviewing work another session produced.
- **debug-and-verify**: on any failing build, test or unexpected behaviour, and before claiming anything is fixed or done.
